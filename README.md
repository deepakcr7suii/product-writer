# Product Description Writer

An AI-powered web app that generates professional product descriptions for online sellers (Amazon, Shopify, Etsy, Flipkart).

## What it does

- Takes a product name and key features as input
- Generates a 200-word product description
- Provides a short version for social media
- Suggests SEO keywords

## Built with

- HTML, CSS, JavaScript
- Claude API (coming soon)

## Status

Working demo version. Real AI integration in progress.

## How to use

1. Open `index.html` in a browser
2. Enter product name and features (one per line)
3. Click "Generate Description"
